# 01 - Prompt 工程

目标：学会写"模型能听懂"的好指令。这是所有 LLM 应用的地基。

## 背景知识（对应吴恩达课程）
- 原则一：写**清晰、具体**的指令（给格式、给例子、给角色）
- 原则二：给模型**思考时间**（让它先分析再下结论）

## 分步任务

### 任务 1：感受"烂 prompt"和"好 prompt"的区别
打开 `practice.py`，补全 `TODO 1`。先用一句话的烂 prompt 让模型总结商品评价，再换成详细版，对比两次输出。

### 任务 2：用分隔符圈定内容
补全 `TODO 2`。学会用 `"""` 或 `###` 把"指令"和"要处理的内容"分开，避免模型把内容当成指令。

### 任务 3：让模型按格式输出
补全 `TODO 3`。要求模型输出 JSON（包含"优点""缺点""评分"三个字段），体会结构化指令的写法。

### 任务 4：给模型一个例子（Few-shot）
补全 `TODO 4`。先给模型看一个"输入→理想输出"的例子，再让它处理新的输入，对比和任务 1 的区别。

### 任务 5：让模型先思考再回答
补全 `TODO 5`。让模型先列出推理步骤，再给出最终结论。观察回答质量的变化。
