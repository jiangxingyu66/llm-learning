# LLM 学习练习场

这个仓库是你的 LLM 动手练习基地。看文档能看懂、但写不出代码——解法只有一个：**跟着任务动手做**。

## 目录结构（每个文件夹是干嘛的）

| 文件夹 | 内容 |
|---|---|
| `00-准备工作` | 装环境、配 API Key，跑通第一行代码 |
| `01-Prompt工程` | 写出好 prompt：清晰指令、给模型思考时间 |
| `02-调用大模型API` | 用代码调用大模型：对话、调参数、结构化输出 |
| `03-RAG问答` | 让模型读你自己的文档来回答问题 |
| `04-Agent智能体` | 让模型自己"思考-行动-观察"循环做事 |
| `05-实战小项目` | 做一个属于你自己的完整小应用 |

**学习顺序**：按编号从 00 做到 05，每个文件夹里的 README 都是分步任务清单。

## GitHub 小白指南

- **这个页面是什么**：你正在看的就是这个仓库的主页，每个文件夹点进去都能看到里面的文件和说明。
- **文件怎么来的**：这些练习骨架是我帮你建的。以后你自己在 Cursor 里写代码，推送（push）上来就会出现在这里。
- **怎么在 Cursor 里打开**：
  1. 在 Cursor 里按 `Ctrl+Shift+P`，输入 `Git: Clone`，粘贴这个仓库地址：`https://github.com/jiangxingyu66/llm-learning.git`
  2. 选个本地文件夹，打开，开始写代码。
- **写完代码怎么同步**：改完代码后在 Cursor 的"源代码管理"里点 `+` 暂存 → 写一句改了什么 → 点"提交"→ 点"同步"。刷新这个页面就能看到。

## 学习方法

1. 每个模块先读 README 里面的分步任务。
2. 打开 `practice.py`，里面全是 `TODO`，照着注释把代码补全。
3. 跑起来，报错就把报错信息贴给我，我帮你看。
4. 做完一个模块，告诉我，我给你出下一关的验收题。

> 原则：先让代码跑起来，再追求写得漂亮。能跑的代码 > 完美的想法。
