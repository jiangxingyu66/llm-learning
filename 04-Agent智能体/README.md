# 04 - Agent 智能体（让模型自己干活）

目标：理解 Agent 的核心循环——**思考 → 行动 → 观察 → 再思考**，直到任务完成。

## 先理解 Agent 是什么（一句话）
普通调用是"你问一句、模型答一句"；Agent 是给模型配几个**工具**，让它自己决定"下一步调用哪个工具"，循环直到搞定任务。

## 分步任务

### 任务 1：定义工具
补全 `TODO 1`。先写两个最简单的工具函数：`calculator`（算数学表达式）、`get_weather`（假数据，返回"北京晴，15度"）。工具就是普通 Python 函数，关键是要有清晰的**名字和说明**。

### 任务 2：手写 ReAct 循环
补全 `TODO 2`。这是本模块的核心，循环做这 4 件事：
1. **思考**：问模型"接下来该做什么？调用哪个工具？参数是什么？"
2. **行动**：解析模型的回答，真的去调用那个 Python 函数
3. **观察**：把工具返回的结果告诉模型
4. **重复**：直到模型说"任务完成，最终答案是..."

### 任务 3：跑一个真实任务
补全 `TODO 3`。给 Agent 出题："北京现在多少度？如果去爬山要带什么？"看它能不能自己调用 `get_weather` 查天气，再结合知识给出建议。

### 任务 4：加一个新工具（可选）
给 Agent 加一个 `search_notes` 工具，能搜索 03 模块里的 documents。体会"加工具 = 给 Agent 长本事"。

## 完成标准
- [ ] Agent 能自主调用至少 2 个工具完成一个任务

## 提示
- 让模型输出固定格式（比如 `行动：calculator(2+3)`）会让解析容易得多。
- 设置最大循环次数（比如 5 次），防止模型无限循环烧 token。
